create directory

mkdir /path dir_name

ex:
mkdir dir1 ;creates dir1 in pwd
mkdir /tmp/linux/unix ;created unix dir inside /tmp/linux

to create nested directories use -p

mkdir -p folder1/folder2/folder3

it checks if folder1 present if not it created, next it creates folder2, next it creates folder3
if folder1 present it checks for folder2 if it present it checks for folder3 if not present it creates folder3

ex: mkdir -p /tmp/linux1/unix1/redhat1


rmdir removes empty directory; means it should not have any directory or file in it

rmdir path_to_dir_name

rmdir /tmp/linux1/unix1/redhat1
it removes redhat1 if it is empty

rmdir /tmp/linux1
it throws error because linux1 have unix1, so it is not happy

rm to remove file

rm path_to_file
it will prompt to confirm
ex: rm /tmp/linux1/unix1/cal.txt

rm *
removes all files inside pwd

rm *.conf
removes all .conf files in pwd

rm -f /tmp/linux1/unix1/cal.txt
it will not ask prompt to confirm

rm -r path_to_dir ;will remove directory and all its contents
rm -rd path_to_dir ;will remove directory and all its contents without prompt to confirm

ex: rm -rf /tmp/linux1

removes linux1 and all its files and directories

-f can be used inside scripts which will run in background and not asks prompt
