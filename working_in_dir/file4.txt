to create file ; cat > file.txt
it will allow to enter data to it

if file.txt is already created then if you user : cat > file.txt; will remove old data and allows to add new data

to append new data to existing file use; cat >> file.txt

you can also create file using echo command

echo > new.txt

echo "Hi" > new1.txt ;creates new1.txt and add Hi

echo "Hello" >> new1.txt ;appends new1.txt and add Hello

alias

to check how many alias are there use : alias

alias dog=cat

now you can execute cat program using dog command as well

alias yestu=ls

alias rm=rm -if #default rm value is set with alias
alias ll=ls -l #default ll value is set to ls -l

to remove this alias use : unalias command

unalias yestu
unalias rm

this is lifetime of alias is till the current shell where the command is set to alias
to make it permanent put it inside ~./bashrc file for that user
